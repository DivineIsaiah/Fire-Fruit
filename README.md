# Student Data Extractor

A Windows desktop application for searching academic Excel workbooks by matriculation number and exporting consolidated student records into a new workbook.

Student Data Extractor is built with C++20 and provides a graphical interface for selecting academic sessions, searching student records, processing multiple Excel workbooks, and generating consolidated extraction results.

## Features

* Windows desktop GUI
* Browse and select academic result sessions
* Search Excel workbooks by matriculation number
* Recursively discover Excel workbooks within a session
* Process multiple workbooks in a single extraction
* Detect matriculation-number columns using header aliases
* Extract every matching row without discarding duplicates
* Generate a consolidated Excel workbook
* Continue processing when individual workbooks are unreadable
* Record workbook-level errors and extraction activity in logs
* Automatically manage application data under the Windows user's local application directory
* Windows installer with Start Menu/Desktop shortcuts
* Uninstaller included with the packaged application

## Application Data

Runtime application data is stored under:

```text
%LOCALAPPDATA%\StudentDataExtractor
```

The application uses the following directories:

```text
StudentDataExtractor/
├── RESULTS/
├── OUTPUTS/
└── logs/
```

### RESULTS

Contains the academic Excel workbooks that the application searches.

Example:

```text
%LOCALAPPDATA%\StudentDataExtractor\RESULTS\24-25\
```

### OUTPUTS

Contains consolidated workbooks generated by the application.

Example:

```text
%LOCALAPPDATA%\StudentDataExtractor\OUTPUTS\
```

Generated files follow this format:

```text
extraction_<matric-number>_<timestamp>.xlsx
```

### logs

Contains application logs describing extraction sessions, processed workbooks, errors, and generated output files.

## How to Use

1. Install Student Data Extractor.
2. Launch the application from the Start Menu or desktop shortcut.
3. Select an academic session.
4. Select or confirm the Results folder.
5. Enter the student's matriculation number.
6. Start the extraction.
7. The application searches the available Excel workbooks.
8. Matching records are consolidated into a new Excel workbook.
9. The generated workbook is saved in the `OUTPUTS` directory.

## Supported Input Files

The application processes Excel workbooks with supported Excel extensions.

The current implementation primarily targets `.xlsx` workbooks.

Temporary Excel lock files such as:

```text
~$filename.xlsx
```

may be encountered while processing a directory. These files are not valid workbooks and may be reported in the application logs.

Legacy `.xls` files are not fully supported by the current OpenXLSX-based implementation.

## Extraction Behavior

The application searches workbook sheets for recognized matriculation-number headers.

When a matching matriculation number is found:

* The matching row is extracted.
* Duplicate matching rows are preserved.
* Records from different workbooks are combined.
* The source workbook is retained as part of the extracted record information.
* Unreadable workbooks do not stop the entire extraction process.
* Workbook-specific errors are written to the application log.

If matching records are found, the application generates a consolidated `.xlsx` workbook.

If no matching records are found, no output workbook is generated.

## Building From Source

Clone the repository and enter the project directory:

```powershell
git clone git@github.com:DivineIsaiah/StudentDataExtractor.git
cd StudentDataExtractor
```

Configure the project:

```powershell
cmake -S . -B build -G Ninja
```

Build:

```powershell
cmake --build build
```

## Running the Development Build

The main GUI executable is:

```text
build/StudentDataExtractorGui.exe
```

Run it from PowerShell:

```powershell
Start-Process ".\build\StudentDataExtractorGui.exe"
```

The project also contains a console target used for development/testing:

```text
build/StudentDataExtractor.exe
```

## Running Tests

Run the test suite with:

```powershell
ctest --test-dir build --output-on-failure
```

A successful test run should report that all configured tests passed.

## Building the Installer

After configuring and building the project:

```powershell
cpack --config build/CPackConfig.cmake
```

The generated installer is:

```text
StudentDataExtractor-1.0.0-win64.exe
```

The installer packages the GUI application together with the runtime dependencies required to run it on a Windows machine without the development environment.

## Design Notes

The application separates:

* GUI interaction
* application workflow
* filesystem discovery
* Excel processing
* student record models
* output generation
* logging
* utility functions

The extraction workflow is designed so that an error in an individual workbook does not necessarily terminate the entire extraction session.

## Limitations

* Current input processing primarily targets `.xlsx` files.
* Legacy `.xls` files are not fully supported.
* Header normalization is intentionally limited to known aliases.
* The application currently performs local file processing.
* The current version searches by matriculation number rather than providing general-purpose student search functionality.
